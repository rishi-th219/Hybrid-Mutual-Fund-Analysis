# Hybrid-Mutual-Fund-Analysis
# 📊 Hybrid Mutual Fund Analysis and Recommendation System

This project presents a **hybrid analysis system for mutual funds** that combines multiple evaluation metrics, real-time data fetching, and user input to assess fund performance and suggest investment options.

It’s a compact yet powerful data-driven mini-project for finance-focused data analytics.

---

## 💡 Project Objectives

- Analyze mutual fund performance based on:
  - **NAV growth**
  - **Returns over time**
  - **Fund volatility**
  - **Sharpe Ratio** and other statistical indicators
- Create a hybrid score combining quantitative metrics for each fund
- Help investors make informed decisions using data analytics
